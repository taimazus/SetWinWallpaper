# سهند نما ۱.۸.۱

این نسخه اصلاحات اجرای برنامه، زمان‌بندی، منابع تصاویر و نگهداری داده‌ها را یکجا منتشر می‌کند.

- جلوگیری از اجرای چند نمونهٔ رابط برنامه؛ اجرای مجدد پنجرهٔ موجود را نمایش می‌دهد.
- محدود کردن محرک ورود زمان‌بندی به حساب کاربر جاری، حذف بی‌خطای زمان‌بندیِ ناموجود و پیام فارسی برای رد شدن دسترسی.
- تلاش مجدد ساعتی پس از خطای دریافت و حفظ فاصلهٔ عادی پس از موفقیت؛ جلوگیری از اجرای هم‌زمان وظایف زمان‌بندی.
- اصلاح دریافت تصاویر ایران، موزه و طبیعت منتخب از Wikimedia Commons و حفظ اطلاعات منبع و مجوز.
- اصلاح فراخوانی API صفحهٔ قفل، نگهداری تنظیمات و آرشیو، حذف تصاویر تکراری و گزارش خطاهای تعمیر.
- اصلاح اسکریپت‌های سرویس، خروجی کارت اشتراک‌گذاری، رفتار ویجت و مستندات فارسی و انگلیسی موجود.
- انتشار فایل اجرایی مستقل و بستهٔ پرتابل Windows x64 تنها پس از موفقیت تست‌ها و ساخت.

## بررسی‌ها

مجموعهٔ تست C#، قراردادهای اسکریپت PowerShell و ساخت مستقل Windows x64 در CI این commit اجرا می‌شوند. تست‌ها شامل mock هستند و تأیید اجرای واقعی همهٔ عملیات ویندوز محسوب نمی‌شوند.

## سازگاری و بازگشت

تنظیمات و آرشیو موجود حفظ می‌شوند. برای بازگشت، برنامه را ببندید و فایل اجرایی نسخهٔ ۱.۸.۰ را اجرا کنید؛ پیش از جایگزینی، از پوشهٔ `%LOCALAPPDATA%\BingWallpaperPro` نسخهٔ پشتیبان بگیرید. در صورت نصب سرویس، پیش از جایگزینی فایل سرویس آن را متوقف کنید.

## محدودیت‌ها

سیاست سازمانی یا مجوز Task Scheduler ممکن است همچنان ثبت زمان‌بندی را رد کند. ثبت واقعی زمان‌بندی روی دستگاه کاربر و اعمال واقعی صفحهٔ قفل، سرویس و سیاست‌های سازمانی جزو تست‌های خودکار این انتشار نیستند. دسترسی منابع اینترنتی به شبکه و سرویس مقصد وابسته است.
